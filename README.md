# Smart EV Charging Station Locator & Slot Booking System

SIH 2026 Project

## Overview

AI-powered, route-aware EV charging platform with:
- Smart charging station discovery
- Real-time charger availability
- Slot booking
- Route-aware charging
- AI voice assistant
- Vehicle compatibility
- Emergency assistance

## Tech Stack

### Mobile
Flutter + Dart

### Web
React + Vite + TypeScript

### Backend
Java + Spring Boot

### Database
MongoDB Atlas

### AI
Groq

### Maps
Google Maps Platform

### EV Data
Open Charge Map

## Repository Structure

- `mobile/` — Flutter Android application
- `web/` — React operator dashboard
- `backend/` — Spring Boot backend
- `shared/` — Shared contracts/documentation
- `docs/` — Project documentation
